# NetLogik signature assets

Public images and icons for email signatures, served through GitHub Pages.

Everything committed to this repository is publicly accessible. Upload only approved signature artwork and icons. Never include credentials, account exports, email messages, HTML signatures, personal documents, or private configuration.

## Layout

Use client/version folders, starting with spk-travel/v1/. Treat published versions as immutable: create a new version when artwork changes so existing signatures keep working.
